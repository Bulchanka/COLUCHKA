# Demo runbook

1. `npm install`
2. `npm run dev`
3. Откройте `/login`.
4. Войдите как Анна Петрова для patient flow или Елена Смирнова для doctor flow.
5. На `/patient/check-in` создайте запись, подтвердите AI summary, затем откройте историю.
6. На `/patient/assistant` отправьте сообщение помощнику и подтвердите запись: она попадёт в ту же историю.
7. Выйдите и войдите как врач, чтобы открыть `/doctor/patients/anna`.
